# DSH 来源追溯配对试验（独立于已完成的冲突试验）

日期：2026-11-12。问题：多层转述、综合汇报、仅引用而非衍生、同文但关系未知并存时，来源图是否帮助 DSH 正确追溯记录的源头？不将来源家族等同统计独立证据，不测真假判断或概率校准。

## 固定设计

- 使用未修改的插件 v0.1.0（核心源码 3406417cfcec0a6950795302a0a28ef7c1dc55cb）与 DSH checkout 8bd073392eef6f54e921a093b95076248eb08cbb。
- 6 个预先生成的固定图，共 192 条材料；包含单层/多层转述、多父汇总、citation-only 的新观察、同文但来源未知、同 URL 的不同摘录。每图查询全部来源家族数及 4 条指定材料的源头集合。
- 第一图的两条根材料取自已核查 NASA/NOAA 2023 年公告的短释义；其余传播链及其余图是合成工作流。不能称为真实网页传播网络或真实多 Agent 实地评测。
- 所有组获得完全相同的文本、来源 ID、URL、已记录引用/衍生边。普通精确文本去重保留全部别名元数据和边。插件使用生产版 Store/project，不附加人工答案。
- 原始材料、普通文本去重、插件视图三组，各按种子 107、211、307 打乱材料和问题顺序。9 次主要 Session 使用 Native 工具直接读材料；额外 3 次使用 seed=107 与 DSH 原生 PTC，允许模型写 JavaScript 计算图，三组都允许。两种执行模式分别报告，不择优合并。
- 同一模型 deepseek-official/deepseek-flash，reasoning=low，每次 completion 上限 16384 token，Session 最多 8 次 completion、300 秒。真实登录、实际正式工具及 Session。
- 工具 origin_packet 返回固定材料。Native 组只有该工具；PTC 组可用 run_code 调用它并任意处理返回数据。禁止额外联网及其他工具。此限制是受控比较，不能外推为原始 DSH 没有代码执行能力；PTC 补充专门检查代码能力。
- 所有组同一指令，明确只沿 derivation 追溯，citation 不合并源头；没有 derivation 父项时以本条 source_id 为根。同 source_id 共享根，未知关系不自行补边。
- 输入及答案在首次模型运行前冻结并记录 SHA-256；不因结果未达到预期调整图或重跑。所有运行都公开，包括错误、未完成和反向变化。

## 评分与边界

独立 oracle 通过生成时的拓扑顺序传播根集合，不调用生产版 ancestry/project 计算金标准；另用 Python 对输入图独立反向遍历核对。精确计数、查询根集合完全相等、未知独立性处理分别计分，漏根和额外根分别列出。未完成/协议错误单列，不算作基线推理错误。

配对收益必须是同图同顺序基线完成但错误、插件正确；反向变化同样报告。重复同一图不增加独立样本量。3 种输入的代码辅助结果是强对照；若都正确，结论应是工作流或成本差异，而不是 DSH 做不到。

报告主 Agent provider usage（输入含缓存、输出、总量）、正式工具调用与耗时；后台会话标题请求单独计数，不把主 Agent 总量称为账单费用。成本包含失败调用，不能仅保留成功调用。
