# 来源追溯实验：准确率未拉开，开销取决于执行方式

2026-11-12，插件核心固定 v0.1.0（`3406417`），实际 DSH checkout `8bd0733`、headless、正式 Native/PTC 工具、真实 `deepseek-official/deepseek-flash` 模型，reasoning=low。

**结论：本次没有发现原始 DSH 漏掉而插件正确恢复的来源关系。** 工程上的成本差异不能改写成错误率或过度自信改善。

## 输入与公平性

六张固定图、192 条材料、每图四条源头查询。包含最长 11 层衍生、多父汇总、仅引用旧报道的新观察、同文但未知关系和同 URL 的不同摘录。每例还要报告全图来源家族数。

G01 的两个根材料是 NASA/NOAA 2023 年公告的简短释义；其余转述链及其他图为合成工作流。**没有实际启动子 Agent 生成传播链，也没有自动从网页发现引用。**

原始材料、保留全部来源别名和边的普通精确去重、生产 `Store/project` 产生的插件视图使用相同事实。独立 Python 检查全部正文、ID、URL 和引用边均保留，并以反向遍历核对标准答案。三种顺序是同六图的重复，不是 18 个独立现实案例。

提示明确要求只沿 derivation 追溯，citation 不合并，独立性报 unknown。因此独立性字段正确不能作为“模型自发避免过度自信”的证据。来源家族也不是统计独立证据数。

## 有效结果

Native 直接读取材料，三种顺序各一次：

| 方法 | 来源家族数正确 | 源头集合正确 | 额外/遗漏源头 | 主 Agent 总 token |
|---|---:|---:|---:|---:|
| 原始材料 | 18/18 | 72/72 | 0/0 | 109,137 |
| 普通文本去重 | 18/18 | 72/72 | 0/0 | 114,205 |
| 完整插件视图 | 18/18 | 72/72 | 0/0 | 127,672 |

完整插件视图较原始材料多约 17% token。它保存了更多来源元数据，不应宣传为通用压缩器。

PTC 允许 DSH 写 JavaScript 处理结构化工具结果；seed=107 每组一次：

| 方法 | 家族数/查询正确 | 主 Agent 总 token | completion 次数 | 耗时 |
|---|---|---:|---:|---:|
| 原始材料 + PTC | 6/6、24/24 | 79,281 | 5 | 25.8 秒 |
| 普通去重 + PTC | 6/6、24/24 | 69,937 | 8 | 44.7 秒 |
| 完整插件视图 + PTC | 6/6、24/24 | 18,927 | 4 | 48.3 秒 |

本次 PTC 插件视图比原始材料少约 76% token，但没有更快。单次 PTC 运行只支持该观察，不足以证明稳定的成本优势。原始 DSH 确实成功编写图遍历代码，不能说它没有这种能力。普通去重在第八次 completion 给出了正确的完成事件，同时碰到计步上限；原始状态、完整答案和时间均保留，没有改成“未完成”。

据此新增精简来源查询 `evidence_trace`，另做匹配的 [性能复测](TRACE-QUERY-EXPERIMENT.md)。该复测复用这些图，是针对已发现开销的工程优化，不是独立验证集。

## 投送错误与修正

第一次接口一次返回全部材料（88–115 KB），触发 DSH spill-policy 保留头尾。DSH 会写出可恢复完整文件，但本实验禁用文件工具，造成原始、去重、插件三组都取不到完整材料并重复调用。三组首轮未完成，第四运行被主动终止。

这是实验接口设计错误，**不算 DSH 推理失败或插件收益**。所有记录及消耗保留在 [无效批次](results/origins/invalid-transport-v1/INVALID.json)。修正后全部组统一按案例分页，模型、预算、输入图和评分不变；两版输入 SHA-256 完全一致。首次协议提交 `f61c005`，统一修正提交 `26a64aa`，有效运行在修正提交之后开始。

最终审核检查实际 Session 的每个 Native 完整工具结果，与冻结页面逐字节语义哈希匹配；PTC 检查发送给程序的页面哈希，并保存模型编写的程序。CLI 的 8 KiB 展示截断与实际 spill 是两种机制，不能只看 CLI 判断模型拿到了什么。
