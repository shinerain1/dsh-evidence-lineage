# 真实案例：2023 年全球温度报告的转载与汇总

研究对象限定为 **2024 年 1 月发布的 2023 年结果**，不把它当作当前最新年份排名。

| 材料 | 可核查事实 | 本实验记录 |
|---|---|---|
| [NASA 新闻稿](https://www.nasa.gov/news-release/nasa-analysis-confirms-2023-as-warmest-year-on-record/) | 2024-01-12、Release 24-008，NASA GISS 分析，1951–1980 基线 | NASA 来源家族 |
| [能源部托管 PDF](https://www.energy.gov/sites/default/files/2024-02/094.%20Roxana%20Bardan%2C%20NASA%20Release%20Analysis%20Confirms%202023%20as%20Warmest%20Year%20on%20Record.pdf) | PDF 页脚直接印有 NASA 原文地址，标题和编号一致 | 选用段落是 NASA 新闻稿的副本，不增加能源部独立研究 |
| [NOAA 公告](https://www.noaa.gov/news/2023-was-worlds-warmest-year-on-record-by-far) | NOAA NCEI 分析，1.18°C 相对 20 世纪平均值 | NOAA 来源家族 |
| [NOAA Climate.gov 图文](https://www.climate.gov/news-features/featured-images/2023-was-warmest-year-modern-temperature-record) | 作者为 NOAA NCEI，介绍同一年度 NOAA 结果 | NOAA 年度分析的同源表达 |

本次人工核查时间：2026-11-12。URL 关系、标题、原始作者及统计基线可以从以上页面核对。

`examples/cases.json` 中使用**作者编写的短释义**，没有上传完整网页、PDF 或图片。相同分析的释义在原文与转载条目中保持一致，另外加入两条**模拟 Agent 汇报**。因此它是基于真实可核查关系的小案例，不是自然采集的大规模网页评测数据集，也不是完整自动抓取/来源发现试验。

6 条材料归为 2 个记录的分析家族；4 条不同内容继续保留。NASA 与 NOAA 使用不同参考期，差异不会因同谈一个年份而被抹除。两套分析也可能共享观测数据，**不能据此把 2 个家族写成 2 次统计独立验证**。

后续扩大评测应加入真实多源混合报道、被更正的原文、没有署名的转载、引用已失效页面，以及盲审标注的段落级来源关系。首版未验证这些情况下的自动来源发现准确率。
