# 精简来源查询：真实 DSH 中的记账差错与成本改进

2026-11-12。插件 v0.2.0，生产实现 commit `801f148`；协议及输入先提交 `5aa9be9`，之后开始 18 次真实 DSH headless Session。DSH commit `8bd0733`，真实模型 `deepseek-official/deepseek-flash`、reasoning=low。

**可支持的改进：把已记录来源图的记账固化为工具，并针对来源查询减少上下文开销。** 这不是新增冲突检测器，也没有验证“错误结论率/置信度得到改善”。

## 找到的具体错误

在 `native-107-raw` 和 `ptc-107-raw` 中，原始 DSH 的指定材料源头查询正确，但把全图不同材料地址/来源 ID 的数量当成了最终源头家族数。G02 有 30 条材料、一个衍生源头，原始组报 30；完整插件和新精简查询报 1。

PTC 组实际生成的程序包含这一记账步骤：

```javascript
for (const m of e.material_index) {
  src[m.id] = m.source_id;
  allSources.add(m.source_id);
}
// 后续把 allSources.size 用作 recorded_origin_count。
```

这数的是所有材料自己的 source_id，而非沿 derivation 追溯后的根集合。插件通过已测试的图遍历计算各材料的根，再对根集合取并集。**原始 DSH 有能力写出正确算法**；第一阶段全部正确，复测其他运行也可能正确。这里发现的是临时生成代码/汇总时会出现的一类具体错误，不是“原始 DSH 永远做不到”。

查看 [原始 PTC 程序](results/trace-query/ptc-107-raw-tool-trace.json)、[原始回答](results/trace-query/ptc-107-raw-final.json)、[新接口回答](results/trace-query/ptc-107-trace-final.json)。每次整体计数策略错误影响同一 Session 中的多题，不能把这些题当成相互独立的失败。

PTC 原始组 seed=211 在 8 次 completion 之后未交付最终 JSON，6 个案例单列为未完成，不记为错误答案。其第八步代码已经算出正确来源数，只是仍在核查并需要下一轮形成最终回答；不能据此声称原始 DSH 不会计算。seed=307 在第八步输出了完成事件及完整答案，因此按已完成评分。原始结果 JSON 中未完成行的 `missing` 是缺少最终输出，不是有效证据被误删；上表查询正确率仅以已完成案例为分母。

- native 内，新接口较原始 DSH 材料的三次总量少 **80.3%** token；逐次减少范围 79.4%–81.0%。
- native 内，新接口较原插件完整视图的三次总量少 **83.9%** token；逐次减少范围 83.4%–84.1%。
- ptc 内，新接口较原始 DSH 材料的三次总量少 **81.0%** token；逐次减少范围 57.0%–89.9%。
- ptc 内，新接口较原插件完整视图的三次总量少 **63.2%** token；逐次减少范围 27.7%–76.6%。

PTC 原始组三次总量包括这次未完成尝试的已报告 usage，因此 81% 左右的总量差不是“双方全部正确完成后的费用差”。它是相同预算下的三次计划运行开销比较；全部原始 usage 和完成状态均公开。每组模型阶段及后台标题请求也不能等同实际账单。

完整输入字节数分别为原始 88,156、完整插件 115,086、精简查询 6,597。**字节与 provider token 分别测量，没有相互换算。** 后者只返回本任务需要的源头对应项；这是按查询返回计算结果的收益，不是把整个研究材料无损压缩到 6.6 KB。

## 新接口做了什么

`evidence_trace(case_id,evidence_ids,offset?,limit?)` 是新增的正式工具，支持 Native 与 PTC。最多选择 20 条材料，每页最多 200 个材料/源头对应项，显式返回分页状态、案例修订和未知独立性声明。使用现有来源图语义，**没有新增来源关系推断、依赖权重或置信度算法**。原文、引用边和导出仍可查询。

原始 DSH 在 PTC 中可以编写图计算代码；本插件把这段易写错的重复记账操作变成已有工具。PTC 可直接处理结构化返回值，避免把整个图反复放进模型上下文。工具适配、宿主 Session 身份、当前搜索服务、持久化恢复都复用 DSH 扩展机制。

## 范围与限制

- 六张图不是六个真实网页传播网络：仅 G01 的两个根事实基于 NASA/NOAA 公告，其余传播链是合成工作流。没有自主网页检索或实际子 Agent 生成链路。
- 来源边预先给定，所有完整输入与第一阶段哈希一致。错误或遗漏的关系仍会影响插件结果；源头家族数不证明统计独立。
- 本阶段看到第一阶段开销后增加精简接口，复用相同数据测试性能；不是独立语义验证集。每组的三个顺序也不是三个独立真实样本。
- 提示要求 independence=unknown，因此该字段正确不能证明模型自发降低过度自信。没有测概率校准、结论真假或开放环境中的来源发现准确率。
- 主 Agent token 包含输入/缓存与输出，以及同一运行中的重复调用；后台标题请求未计 usage，不能称为完整账单。耗时受服务和启动影响，保留原始值但不作速度保证。
- [第一阶段](ORIGIN-EXPERIMENT.md) 的全正确结果和无效投送尝试都保留，未用新结果覆盖。初版超长投送缺陷是实验接口错误，不算插件收益。
